An old ThinkPad, wiped down to headless Ubuntu Server: no desktop environment, no display manager, boots straight to a login prompt over SSH or a bare tty. The single purpose is longform writing, a novel draft, a poetry chapbook, a series of essays, one manuscript at a time, kept off the machine that also runs email and a browser.

I'm going to be using [Micro](https://micro-editor.github.io/) for plain prose, as it has sane defaults and no modal keybindings to relearn. I'll use [WordGrinder](https://cowlark.com/wordgrinder/) for chapters or scenes, it's a distraction-free word processor that saves to a portable format. See [[micro-controls]] and [[wordgrinder-controls]] for the keybindings.

[[manuscript-render-script|Git]] is how work leaves the machine, pushed from `~/manuscripts` to a private repo. See [[obscure-netlify-subdomain]] for how to use Beeminder with it, and [[monospace-fonts]] for the terminal fonts.
