A collection of favorite monospace typefaces designed for coding, terminal applications, and technical writing. These fonts prioritize legibility at small sizes and character disambiguation for programming environments.

## Programming Fonts with Ligatures

### [Fira Code](https://github.com/tonsky/FiraCode)
Monospaced font with ligatures for common programming combinations by Nikita Prokopov (c. 2014-2015). Based on Fira Sans from Mozilla. Features hundreds of ligatures, arrow support, and progress bar glyphs.

### [Cascadia Code](https://github.com/microsoft/cascadia-code)
Monospaced font by Aaron Bell at Microsoft (2019), bundled with Windows Terminal. Programming ligatures developed alongside Windows Terminal. Multiple variants including Code, Mono, and Powerline/Nerd Font versions.

## Traditional Monospace

### [Hack](https://sourcefoundry.org/hack/index.html)
Monospaced typeface by Chris Simpkins at Source Foundry. Large x-height, wide aperture, and low contrast for legibility at coding sizes (8-14px). Based on Bitstream Vera & DejaVu projects with Powerline glyphs.

### [Source Code Pro](https://fonts.google.com/specimen/Source+Code+Pro)
Monospaced sans-serif by Paul D. Hunt for Adobe (2012) as companion to Source Sans. Long x-height, dotted zero, and optimized shapes for coding characters. Seven weights with italics added in 2015.

## Iosevka Family

### [Iosevka Charon Mono](https://fonts.google.com/specimen/Iosevka+Charon+Mono)
Monospace font tuned for coding and terminal use by Juliette (jul-sh). Google Fonts-compliant version of Iosevka family. Excellent for technical writing and dense UI.
